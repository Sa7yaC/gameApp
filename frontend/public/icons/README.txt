GAME ICON SHEET EXPORTS
=======================
Export the icons from the 3D icon sheet as individual PNGs (transparent background)
into this folder with exactly these filenames. The app picks them up automatically;
until a file exists, the built-in vector icon is shown instead.

Primary action:
  create-room.png      people + plus badge      (Create Room card icon)
  join-room.png        arrow into door          (Join Room card icon)
  start-game.png       yellow play button       (Start Game button)
  invite.png           blue share               (Invite Friends button)
  copy.png             purple copy              (room code copy / paste buttons)
  regenerate.png       circular refresh         (nickname roll button)

Status:
  ready.png            green check              (Ready pill / Guessed tag)
  not-ready.png        gray clock               (Not Ready pill)
  current-turn.png     hourglass                (Current Turn tag)
  room-full.png        people + minus           (Room Full chip)

Badges & trophies:
  host-crown.png       gold crown               (Host badge / winner crown)
  trophy.png           gold trophy              (spare)

Meta / info:
  year.png             purple calendar          (movie year hint chip)
  category.png         black clapperboard       (movie category chip / rows)
  info.png             blue info                (spare)
  settings.png         purple gear              (Game Settings header)
  help.png             question mark            (text hint chip)

Navigation:
  leave.png            red exit                 (Leave Room button)
  home.png             house                    (spare)
  profile.png          person                   (homepage username avatar)

Cinema:
  movie.png            clapper + popcorn        (Players panel icon / empty states)

Emoji keyboard tabs (optional — falls back to native emoji icons):
  cat-smileys.png      smiley                   (Smileys & People tab)
  cat-animals.png      teddy bear               (Animals & Nature tab)
  cat-food.png         burger                   (Food & Drink tab)
  cat-activities.png   football                 (Activities tab)
  cat-travel.png       airplane                 (Travel & Places tab)
  cat-objects.png      lightbulb                (Objects tab)
  cat-symbols.png      star                     (Symbols tab)
  cat-flags.png        flag                     (Flags tab)
  cat-search.png       magnifier                (Search field)

Decorative (optional, unused for now):
  popcorn.png, film-reel.png, theater-seat.png, ticket.png,
  camera.png, glasses.png, director.png, star.png, film-strip.png
